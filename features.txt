# Knock-Out - 2D Fighting Game Features

## General
- **Genre:** 1v1 2D Fighting Game
- **Technology:** HTML5 Canvas, Vanilla JavaScript (No external game engines)
- **Platform:** Web Browser (Desktop)
- **Audio:** Web Audio API (Synthesized SFX, no external assets required)

## Game Modes
- **Single Player (PvE):** Battle against an AI opponent with dynamic behavior (Chase, Attack, Retreat, Jump).
- **Two Player (PvP):** Local multiplayer on a single keyboard.

## Gameplay Mechanics
- **Physics:** Custom gravity and velocity-based movement system.
- **Combat System:** 
    - Melee attacks with precise hitbox collision detection.
    - Attack cooldowns to prevent button spamming.
    - "Take Hit" states with visual feedback (stun animation).
    - Strict frame-based hit validation to prevent glitches.
- **Health & Rules:**
    - Dynamic health bars that deplete on impact.
    - 60-second round timer.
    - Win Conditions: Deplete enemy health (KO) or have higher health when time expires.
    - Draw detection (Double KO or equal health at timeout).
- **Boundaries:** Screen edge collision prevents players from walking off-screen.

## Controls
- **Player 1 (Samurai Mack):**
    - **Move:** A / D
    - **Jump:** W
    - **Attack:** Spacebar
- **Player 2 (Kenji):**
    - **Move:** Arrow Left / Arrow Right
    - **Jump:** Arrow Up
    - **Attack:** Arrow Down
- **System:**
    - **Start Game:** Click Menu Buttons.
    - **Restart:** Press 'Enter' after Game Over.

## Visuals & User Interface
- **Sprite Animations:** Professional pixel-art assets with full frame-by-frame animations:
    - Idle, Run, Jump, Fall, Attack, Take Hit, Death.
- **Dynamic Orientation:** Characters automatically flip sprites to face their movement or opponent.
- **Environment:**
    - Animated background shop.
    - Scrolling parallax-style background.
- **Screens:**
    - **Main Menu:** Full-screen start menu with controls guide and mode selection.
    - **HUD:** High-contrast health bars and timer overlay.
    - **Game Over:** Centered overlay with winner declaration and restart prompt.

## Audio (Synthesized)
- **Jump:** Retro rising pitch beep.
- **Attack:** Quick "whoosh" noise.
- **Hit:** Low crunch/impact sound.
